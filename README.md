# TopOnzMaticooAdapter

zMaticoo iOS SDK ↔ TopOn / AnyThinkiOS mediation adapter.

## Version

`2.2.0.1`

## Integration

Latest（默认，AnyThinkiOS > 6.4.92）：

```ruby
pod 'TopOnzMaticooAdapter', '2.2.0.1'
```

Legacy（AnyThinkiOS ≤ 6.4.92）：

```ruby
pod 'TopOnzMaticooAdapter', '2.2.0.1', :subspecs => ['Legacy']
```

> `Latest` 与 `Legacy` 类名相同，同一 target **只能选其一**。
